SPOTIFOR — website playlist personal

File:
- index.html : struktur halaman
- style.css  : desain responsif dan gaya visual
- script.js  : navigasi, editor, penyimpanan, galeri, dan pemutar audio

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html di browser modern.
3. Tekan ikon pensil (✎) untuk mengganti nama, teks, foto, dan lagu.
4. Pilih file audio milikmu (MP3/M4A/OGG/WAV) agar pemutaran lagu penuh berfungsi.
5. Klik Simpan perubahan.

Catatan:
- Data teks tersimpan menggunakan localStorage pada browser/perangkat tersebut.
- File foto dan audio yang diunggah dipakai selama sesi halaman; browser tidak menyimpan file audio besar secara permanen ke localStorage.
- Foto contoh memerlukan koneksi internet. Ganti dengan foto sendiri melalui editor.
- Lagu penuh harus diunggah sendiri. Judul lagu saja tidak menyediakan akses ke audio Spotify penuh.
